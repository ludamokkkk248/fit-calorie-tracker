# 燃卡 FitCal · 增肌减脂卡路里计算器

一个**完全属于你自己**的健身饮食管理应用：
不用注册、不用登录、没有广告、没有会员，所有数据只存在你自己的设备上。

## ✨ 功能

| 功能 | 说明 |
|---|---|
| 🎯 专属计划 | 按你的身高、体重、体脂率(肌肉量)、日常活动量、训练水平，自动算出增肌/减脂/维持所需的每日热量和蛋白质·碳水·脂肪目标 |
| 📒 饮食记录 | 早餐/午餐/晚餐/加餐分开记，实时显示"还能吃多少"，三大营养素进度条 |
| 🍗 食物库 | 内置 180+ 种中国常见食物、饮料、快餐、补剂的热量表（每100克的碳水/蛋白/脂肪） |
| ➕ 自定义食物 | 手动录入任何食物的营养数据，永久保存在"我的食物" |
| 📷 拍照识别 | 拍包装背面的「营养成分表」，自动识别热量/三大营养素并换算（千焦自动转千卡，"每份"自动折算到每100克） |
| 📱 可安装 | 支持 PWA：像 App 一样安装到电脑桌面和手机主屏幕，离线也能用 |
| 💾 数据备份 | 一键导出/导入 JSON 备份文件 |

## 🖥️ 在电脑上使用（3 步）

1. **双击 `启动燃卡.bat`** —— 会弹出一个黑色窗口（这是本地服务器，别关），浏览器自动打开应用
2. 首次进入按引导**填写身体资料** → 点「⚡ 生成我的计划」
3. 想装成桌面 App：看浏览器**地址栏右侧的安装图标**（⊕ 或电脑+↓小图标），点它 → 「安装」。
   之后桌面就有「燃卡」图标了，安装完成后**即使不开黑色窗口、断网也能用**（数据和应用都缓存在本地）

> 用 Chrome 或 Edge 浏览器效果最好。

## 📱 怎么装到手机上？

手机安装需要一个「网址」——把这个文件夹放到免费的静态网站托管上（比如 GitHub Pages / Cloudflare Pages），
然后用手机浏览器打开那个网址：

- **安卓 + Chrome**：打开网址 → 会自动弹「添加到主屏幕/安装应用」，或点右上角 ⋮ 菜单 → 「安装应用」
- **iPhone + Safari**：打开网址 → 点底部「分享」按钮 → 「添加到主屏幕」

装好后和普通 App 一样：全屏、有图标、离线可用。
（让 AI 助手帮你部署即可，整个过程免费，不需要写代码）

## 📷 拍照识别小技巧

- 拍包装**背面的营养成分表**（就是那个小表格），不是正面
- 光线足、拍正、表格占满画面，识别率最高
- 首次使用需要联网下载识别引擎（十几秒），之后会缓存
- 识别结果会让你确认修改后才保存——记得核对一眼
- 图片**只在你的设备上处理**，不会上传到任何地方

## 📏 怎么记录才准？

- 建议买个**厨房秤**（十几块钱），前两周称一称，很快就有"眼力"了
- 内置食物都标了常见份量（如"1碗约150g"），没秤时按这个估
- 米饭、面条等主食记**熟重**；鸡胸肉等标了（熟）/（生）注意区分
- 炒菜的油别忘了记（每盘菜约 10-15g 油）

## ⚙️ 计算原理（想了解的话）

- 填了体脂率 → 用 **Katch-McArdle 公式**（按瘦体重=肌肉量算，健身人群更准）
- 没填体脂率 → 用 **Mifflin-St Jeor 公式**（目前公认误差最小的通用公式）
- 减脂：热量缺口 15-20%，蛋白质 1.8-2.2g/kg 保肌肉
- 增肌：热量盈余 8-15%（训练水平越高越保守），蛋白质 1.8-2.0g/kg
- 数据不是越少越好：减脂期掉太快会掉肌肉，App 的缺口设置是"能坚持"的科学区间

## ❓ 常见问题

**Q: 双击 bat 后窗口一闪就没了？**
A: 可能 8137 端口被占用，或电脑没装 Python。右键 bat → 编辑，把 `8137` 改成 `8899` 试试。

**Q: 数据会丢吗？**
A: 数据存在浏览器本地存储里，正常使用不会丢。但**清除浏览器数据**会清掉，重要数据请定期在「我的计划 → 导出备份」。

**Q: 换电脑/手机怎么迁移数据？**
A: 旧设备「导出备份」→ 把 JSON 文件传给新设备 →「导入备份」。

**Q: 食物数据准吗？**
A: 内置数据参考《中国食物成分表》和 USDA 数据库。同名食物不同做法热量差异大（比如清蒸鱼 vs 红烧鱼），包装食品建议直接拍营养成分表最准。
