01

场景与判定

先确认“有库存”，再进入发货动作

快手小店产生新订单后，订单会进入商家后台的 订单管理。此时不能直接发货，必须先到飞书订单表确认这单上游是否已经上单成功、是否有可用快递单号。

本 SOP 只覆盖有库存、可直接发货的情况。若为缺货，请停在判定环节，转入调货/补货流程，避免产生虚假发货。

判定口诀：飞书有“库存”、手上有单号，才允许在快手点“发货”。

作业前提

  • 后台权限订单管理 · 发货
  • 飞书权限可编辑订单表
  • 双屏或分屏建议，减少切换
  • 旗帜规则开工前确认
  • 打单设备按需连接
BRANCH A · 走本流程

有库存

飞书表该订单行已标记“库存”，上游已上单成功，并且能拿到可用的快递单号。按本 SOP 正常发货并标绿旗。

库存上单成功有快递单号
BRANCH B · 停止发货

无库存

飞书表显示缺货或尚未上单成功，没有可用快递单号。此时不发货，先调货/补货，待转为有库存后再回到本流程。

疑似缺货缺货订单项已调货

03

分步操作

截图中的橙色编号与步骤一一对应
01

进入待发货列表，先核对再动手

目的：确认处理对象正确，避免拿错订单、发错货。

快手小店后台
  1. 打开快手小店商家后台，左侧导航点 订单管理。
  2. 顶部切换到 待发货 页签，这里就是当班要处理的订单池。
  3. 用 订单编号 / 物流单号 / 订单状态 / 直发仓库 筛选，点 搜索 缩小范围。
  4. 逐项核对 商品名称与规格、数量、实收金额、收件人姓名 / 手机 / 地址。
  5. 看订单上的倒计时提示，如“21 小时 47 分钟内请完成发货”，按剩余时间从短到长处理。
注意：若订单还在“待审核”，需先完成审核才会进入待发货；视频中两个页签同时存在，按你所在环节选择，不要跨环节操作。
02

复制完整的平台订单号

目的：拿到飞书表中唯一能精确匹配的键。

复制
  1. 在订单卡片左上角找到 订单号：…，从第一位选到最后一位，整段复制。
  2. 示例：110214901202851781，注意不要漏位、不要带空格或换行。
  3. 不要误复制 订单编号、商品采购单号或店铺内部单号，它们与飞书表的匹配列不是同一个字段。
为什么强调“平台订单号”：飞书表用「平台订单号及收入」列登记订单，只有平台订单号能一行对一单；复制错字段会搜不到或对错行。
匹配键
平台订单号
常见错误
复制成订单编号
校验
位数与示例一致
03

在飞书表定位订单，判断是否有库存

目的：确认这单上游已经上单成功，属于可直发状态。

飞书 · 快手订单管理
  1. 打开飞书云文档中的《订单发货状态，跟进管理》表。
  2. 顶部页签切换到 快手订单管理，不要停留在其他平台的页签。
  3. 在 平台订单号及收入 列粘贴订单号定位，或用 Ctrl/Cmd + F 搜索。
  4. 核对行内 商品、店铺、收件信息 与快手订单完全一致。
  5. 看状态标记判断库存：库存 为有库存；疑似缺货 / 缺货订单项 为无库存。已调货 表示已处理调货。
注意：一单一行。若搜出多行，以平台订单号完全一致、且商品规格匹配的那一行为准；状态不是“库存”就停在这里，不要继续发货。
04

取得该订单的快递单号

目的：拿到与这一单对应的、可用于回填的发货凭证。

取单号
  1. 确认该行状态为 库存，且上游已 上单成功。
  2. 从该订单对应的上单/发货记录中复制 快递单号，视频中即从飞书订单记录中复制。
  3. 核对 物流公司 与单号是否匹配，单号位数是否正常。
  4. 单号先放在剪贴板或临时记事中，下一步直接粘贴，避免二次查找。
红线：没有快递单号就不能发货。不要借用其他订单的单号，也不要先点发货再补单号，这两类操作都会形成虚假发货风险。
前置条件
飞书状态=库存
凭证

物流公司 + 单号
05

回到快手后台，回填单号并发货

目的：把订单从“待发货”推进到“已发货”。

快手小店后台
  1. 回到 订单管理，找到刚才那笔订单。
  2. 点订单右侧的 发货；也可先点 查看详情 再进入发货。
  3. 选择正确的 物流公司，把快递单号粘贴到单号输入框。
  4. 确认收件信息无误后提交，订单状态变为 已发货。
注意：发货前再看一眼收件人；不要重复发货。若单号填错，需在发货后尽快按平台规则修改，避免影响物流揽收与考核。
06

标记绿色旗帜，完成订单闭环

目的：让已处理订单在列表中一眼可辨，方便交接与复核。

标记
  1. 在订单列表 勾选 已发货的订单。
  2. 点工具栏 标记，在颜色菜单中选择 绿色。
  3. 视频演示的规则是：定位到该订单所属店铺的订单，统一标成绿旗，作为已处理识别色。
  4. 如团队要求留痕，回到飞书表同步该订单的发货状态或备注。
口径说明：旗帜颜色是团队自定义的视觉标签，系统不校验其含义。视频讲解带有方言口音，店铺名按“陈兴（音）”记录，请在开工前与当班负责人确认颜色对应关系，并保持同一店铺始终一致。

05

异常处理

遇到问题先停手，按表排查
现象常见原因处理方式
飞书搜不到订单号复制成了订单编号；带空格；页签不对重新复制平台订单号，确认在「快手订单管理」页签，再用 Ctrl/Cmd + F 搜索
状态是“疑似缺货”上游无库存或未确认不发货。转调货/补货，状态处理为“已调货”后再发
显示“库存”但没单号上游尚未上单成功等上单成功或联系上游，禁止先发货后补单
发货提示单号无效物流公司选错；单号位数不对核对物流公司与单号，一单一号，不要复用
订单即将超时处理顺序不合理按倒计时升序处理，优先剩余 6 小时内的订单
误标了颜色多选或点错重新勾选该订单，用「标记」覆盖为正确颜色
